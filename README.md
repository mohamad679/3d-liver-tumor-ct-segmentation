# ProtoEM-CT

ProtoEM-CT studies robust transductive few-shot adaptation for 3D CT liver-tumor segmentation, with emphasis on leakage-safe protocol design, robustness evaluation, uncertainty-aware analysis, and external validation discipline. This repository is under phased implementation, and no scientific result should be assumed unless it is regenerated from machine-readable artifacts in the completed workflow.

The repository is currently in Phase 0 scaffolding. See [PROJECT_SPEC.md](PROJECT_SPEC.md), [ACCEPTANCE_CHECKLIST.md](ACCEPTANCE_CHECKLIST.md), and [docs/PHASE_PLAN.md](docs/PHASE_PLAN.md) for the governing scope, gates, and implementation sequence.
